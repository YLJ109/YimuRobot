# 前端 UI/UX 设计文档 — Linear Aesthetic

> 基于 frontend-design Skill 的 Linear Aesthetic 主题，为埃夫特 ER3-600 机器人仿真系统全量重设计。

## 一、设计系统

### 1.1 色彩体系

| 语义 | 变量 | 值 | 用途 |
|------|------|-----|------|
| 画布背景 | `--bg-canvas` | `#050506` | 最底层背景 |
| 表面背景 | `--bg-surface` | `#0A0A0B` | 侧栏/面板背景 |
| 卡片背景 | `--bg-card` | `#0E0E11` | 卡片/单元格 |
| 悬浮背景 | `--bg-elevated` | `#141418` | 按钮/输入框 |
| 主文字 | `--text-primary` | `#EDEDEF` | 标题/重要文字 |
| 次文字 | `--text-secondary` | `#A1A1AA` | 正文 |

## 二、页面布局

### 2.1 整体结构（三栏式）

```
┌──────────────────────────────────────────────────────┐
│ 顶栏 (52px) · 玻璃拟态 · Logo+状态+操作+麦克风        │
├──────────┬───────────────────────┬───────────────────┤
│ 左侧栏    │                       │ 右侧栏             │
│ (296px)  │    3D 主视口           │ (440px)           │
│ 手动控制  │    (Three.js)         │ ┌───────────────┐ │
│ 物体库    │                       │ │ AI 对话面板    │ │
│          │                       │ ├───────────────┤ │
│          │                       │ │ 代码编辑器    │ │
│          │                       │ └───────────────┘ │
├──────────┴───────────────────────┴───────────────────┤
│ 底部状态栏 (32px) · TCP+状态+帧率+持物+吸盘           │
└──────────────────────────────────────────────────────┘
```

### 2.2 响应式策略

- 桌面端 (>1200px): 三栏完整显示
- 平板 (768-1200px): 左侧栏可折叠
- 小屏 (<768px): 侧栏隐藏，可滑出

## 三、交互规范

### 3.1 交互状态

| 状态 | 表现 |
|------|------|
| hover | 边框增亮 + 微上移 1px + 光晕增强 |
| active | 回弹归位 |
| disabled | 透明度 35-40% + 禁止光标 |
| loading | 呼吸动画 + shimmer 扫光 |
| focus | 靛蓝聚焦环 + 光晕 |

### 3.2 动画

- **过渡**: `150ms / 250ms / 400ms` 三档
- **缓动**: `cubic-bezier(0.16, 1, 0.3, 1)` 精密退出
- **呼吸**: 3s 周期，opacity 0.5↔1
- **脉冲**: 1.5s 周期，状态指示点
- **扫光**: 2.5s 周期，45° 光线扫过

## 五、样式架构

```
src/assets/
├── design-system.css   # CSS 变量定义（色彩/间距/圆角/字体/阴影）
└── global.css          # 全局重置 + Element Plus 深度覆盖
```

所有颜色/尺寸通过 CSS 变量统一管理，零硬编码。组件内 `<style scoped>` 仅引用变量。
